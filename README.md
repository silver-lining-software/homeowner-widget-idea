# Atix Contractor — Bootstrap Prototype

This prototype recreates the sequence from the supplied wireframes in a more polished HVAC-oriented visual system.

## Files
- `index.html` — page structure and Bootstrap components
- `styles.css` — custom responsive UI system
- `app.js` — prototype interactions for sign-in and verification

## Included flow
1. Project finder home
2. Guest account dropdown
3. Sign-in modal
4. Email verification modal
5. Signed-in state
6. Optional mock Google sign-in

## Run
Open `index.html` in a browser with internet access so the Bootstrap, Bootstrap Icons, and Inter font CDN resources can load.

## Notes
The email verification and Google actions are prototype-only. Connect them to your backend/SSO service in production.

## Additional screen
- `workscope.html` — Workscope Design Data / Fossil Fuel Type screen
- `workscope.css` — styles for the Workscope screen

## Additional flow screens
- `project.html` — Project Info screen with map-style hero and floating form card
- `customer-info.html` — Customer contact information screen
- `proposal.html` — Final proposal review screen
- `flow-screens.css` — Shared styles for the flow screens above

### Proposal enhancement
The proposal view includes **Project Duration** in the top summary and again inside the Project Info section.
